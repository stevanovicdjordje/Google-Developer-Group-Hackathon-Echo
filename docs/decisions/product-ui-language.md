# UI language for the demo

- **ID:** `product-ui-language`
- **Status:** accepted
- **Writer:** Product holder · @Ilij4n
- **Affects:** mobile, feature:maps
- **Created:** 2026-10-11 · **Decided:** 2026-10-11

## Context

The video and the app need one language. The app skeleton is in English; the map package and the old dev screen are in Serbian.

## Options

- English
- Serbian

## Decision

**English** for the app UI and the demo video. Serbian stays available as a translation target (Echo translate button, l10n later).

## Consequences / follow-ups

- Mobile: English is the default/template language (unblocks board task M-11).
- feature:maps: English strings for the map screens shown in the video (request via `mobile/STATUS.md`).
